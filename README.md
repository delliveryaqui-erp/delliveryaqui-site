# Dellivery Aqui — ERP para Restaurantes

O **Dellivery Aqui** é uma plataforma completa de gestão (ERP) desenvolvida especificamente para o setor de alimentação, incluindo restaurantes, lanchonetes, pizzarias e redes de franquias. Este repositório contém o **site institucional** do produto.

## 🚀 Funcionalidades do Sistema

- **Gestão de Pedidos:** Centralização de pedidos do salão, delivery e integração com apps (iFood, Rappi).
- **Controle Financeiro:** DRE automático, fluxo de caixa e conciliação bancária.
- **Estoque Inteligente:** Alertas de reposição e ficha técnica por prato.
- **RH Digital:** Gestão de escala, ponto e comissões.
- **App Próprio:** Cardápio digital e programa de fidelidade com a marca do restaurante.
- **Conformidade Fiscal:** Emissão de NF-e, NFC-e e SAT.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e SEO-friendly.
- **CSS3:** Estilização moderna com variáveis (:root), Grid, Flexbox e animações premium.
- **JavaScript:** Interações de scroll, efeitos de revelação (Intersection Observer) e navegação.
- **Google Fonts:** Tipografia Playfair Display e DM Sans.

## 💻 Como Visualizar

O projeto é uma aplicação web estática. Para visualizar:

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Para uma experiência melhor de desenvolvimento, utilize extensões como o "Live Server" no VS Code.
